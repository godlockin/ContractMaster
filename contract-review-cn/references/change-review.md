# 合同 V1 → V2 修改审核

AI IDE 持续维护同一交易时优先使用 [案例目录管理](case-management.md)，按稳定文件编号比较任意两份合同组快照。下文 prepare-change 是独立运行入口，其按参数顺序配对的限制不适用于案例脚本。

用户提供原版及对方返回版，要求“审核修改”“对比修订”“检查细微改动”时，使用本流程。报告的 `--revision` 仅保存审核报告历史，不会比较合同版本。

## 本地准备

```bash
python3 "$SKILL_DIR/scripts/pipeline.py" prepare-change \
  --before /本地/合同V1.docx --before /本地/附件V1.txt \
  --after /本地/合同V2.docx --after /本地/附件V2.txt \
  --run /本地/新审核目录
```

两侧至少各一份输入；可附加 `--entities /本地/实体词典.json`。按各侧参数顺序配对，不按文件名自动匹配。末尾未配对文件计为整份新增/删除。附件缺失或次序不同须先核对配对清单；中间缺失附件不能直接错位传入。新版原件变化须新建运行目录。

两版联合脱敏，共用实体标记；候选包仍只保存在 private。用户本地核对两版提取完整性、配对关系、脱敏质量后，沿用 [workflow](workflow.md) 的 release、专家规划、审核、验证及报告步骤。未经当前输入的提取与隐私复核，不分发候选内容。

DOCX 比较采用最终文本投影：排除删除及移出文本，保留插入及移入文本。不是完整 Word 修订引擎；表格结构、属性修订、格式、图片、签章及复杂版面须本地可视核对。PDF 分页文本按输入文件汇合比较；提取顺序或页眉差异仍可能形成噪声。

## 差异及审查范围

公共包的 `comparison` 包含 source pairs、完整操作账本、changes 及 `comparison_digest`。账本保留未修改区间；新增、删除、替换提供两版原文证据及字符位置。`move_peer` 仅表示相同文本移动候选，不能认定无影响。细粒度 edit 坐标相对于当前修改块，证据坐标相对于对应 document，均按 Unicode 字符计数。

优先提示计价周期/单位、金额/币种、否定与例外、义务强弱、责任范围/上限、条件/通知、期限、连接词、数字及引用变化。规则提示不是法律结论；没有提示的差异也必须审核，不得用改动字数或相似度判断安全。

例如“未来三年300万/年”变为“未来三年300万”，提示计价基础变化，并给出条件算例：**若原文每年支付、新文为三年总额，则900万 → 300万，可能减少600万**。必须结合总价、付款计划、税费、调整条款核实。多金额、币种冲突、否定/上限/例外等不满足条件时不推算该总额；有限数字解析不覆盖全部中文大写、复杂公式及所有计价表达。

专家逐项解释对我方的收益、义务、触发条件、举证、救济和最坏履行情景影响；关联定义、其他条款及附件，检查跨条款抵消、冲突、遗漏引用及原版既有风险。立场或业务底线未知时双向分析并列待确认事实。全文四轮审核继续执行，不能只审差异片段。

## 结果与完成门禁

每个计划角色在原有结果中增加：

```json
{
  "comparison_digest": "当前比较摘要",
  "change_reviews": [{
    "change_id": "CHG000001",
    "classification": "material",
    "decision": "clarify",
    "unresolved": true,
    "analysis": "改动含义、影响与处理建议",
    "context_note": "与总价及付款计划的联系、待补事实",
    "related_segment_ids": ["实际有效的片段ID"]
  }]
}
```

`classification` 为 material/nonmaterial/uncertain；`decision` 为 accept/conditional/reject/clarify。uncertain 或 clarify 必须 unresolved=true。每角色恰好覆盖每个 change_id 一次；摘要陈旧、遗漏或未知 ID 拒绝验证。没有差异时提交空列表。不得为满足格式编造风险。

[双组质询](dual-team.md) 的每条 cross_challenges 增加 `change_ids` 数组，不涉及差异的质询可为空。每个差异必须有 A→B、B→A 两向质询。逐项裁定需保留原文、理由、上下文与未决事实。

未决修改、单向/遗漏质询、输入提取缺口、大文本退化为粗粒度比较均阻止完整深度。粗粒度情况须分区补审并重新准备可验证输入，不可直接清除阻断标记。报告汇总差异、条件算例、各角色判断及未决项；版本 manifest 绑定比较摘要。

结构校验不能证明专家真实执行、穷尽法律风险或签约安全；生产验收仍见 [能力矩阵](../../docs/PRODUCTION-READINESS.md)。
