# 本地部署验收清单

本清单是 [生产计划](PRIVACY-PRODUCTION-PLAN.md) 的机器级验收补充，记录检查项与证据位置；不替代生产计划，也不代表当前已完成生产部署。

## macOS arm64 与模型运行时

- [ ] 记录 macOS、架构、Python、MLX、`mlx-lm` 固定版本与 lock 文件 hash。
- [ ] 在无真实合同的合成数据上验证训练、加载、推理；记录模型和 adapter hash、显存/统一内存峰值、失败退出码。
- [ ] 对较大模型迁移执行容量、完整性校验与可回滚演练；保留旧 artifact，确认迁移失败不会替换当前默认模型。
- [ ] 实际 MLX 长文 smoke 通过：多块调用、每块 prompt、总预算、canary、普通金额保留、PHONE 脱敏、restore hash。

## 本地数据与恢复

- [ ] 原始文件、private mapping、实体词典、未复核文本目录权限分别核验；原件不进入公开 bundle、日志、Git 或模型输入边界之外。
- [ ] 备份 run、mapping、policy、模型/adapter/runtime 摘要；恢复到临时目录后核对 hash 与权限。
- [ ] 失败、输入变化、词典变化或模型变化均新建 run；禁止覆盖旧 run。release 前完成人工脱敏复核。
- [ ] 记录模型版本回滚命令与回滚后 smoke 证据，默认模型变更需重新评估。

## IDE、插件与宿主边界

- [ ] 管理员实际核验 IDE、插件及连接器可读目录、日志、缓存和上传权限；保留权限快照。
- [ ] 管理员实际核验宿主出站连接、DNS、代理、遥测与子进程网络行为；仅设置离线环境变量不能证明零网络。
- [ ] 核验失败时标记为未验收，不通过改用户配置、禁用正常功能或临时防火墙规则掩盖。
